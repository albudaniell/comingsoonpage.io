# Notification Page

This project is a **"Coming Soon"** page that allows users to subscribe with their email to receive notifications. The design is modern, responsive, and includes interactive components for an engaging user experience.

## Features

- **Email Subscription**: Users can enter their email address to get notified.
- **Responsive Design**: The page adjusts seamlessly to different screen sizes.
- **Interactive Button**: The "Notify Me" button includes hover effects for enhanced interaction.
- **Social Media Links**: Buttons for Facebook, Instagram, and Twitter, styled as circular icons.
- **Visual Illustration**: A dashboard illustration complements the modern design.

## Technologies Used

- **React**: Provides the application's structure.
- **CSS3**: Styles the page elements for an attractive appearance.
- **FontAwesome**: Supplies icons for social media links.

## Project Structure

- **`App.js`**: Contains the logic and structure of the application.
- **`app.css`**: Provides styling for the components.

## Styling Overview

- **Background**: A clean white background for a professional look.
- **Typography**: Contrasting colors for increased readability.
- **Email Input**: Modern styling with rounded corners and focus effects.
- **Social Media Buttons**: Circular buttons with hover effects for interactivity.
- **Footer**: A simple, elegant design for copyright and social media icons.
